# Contributing Guidelines

Thank you for your interest in contributing to this project!

## How to Contribute

### 1. Fork the Repository
Click “Fork” on the repository page.

### 2. Clone Your Fork
```bash
git clone https://github.com/your-username/mongodb-metrics-app.git
```

### 3. Clone Your Fork
```bash
git checkout -b feature/my-feature
```

### 4. Make Your Changes

Follow code style and best practices.

### 5. Test Your Changes

Ensure:

- The app builds successfully
- Kubernetes manifests apply cleanly
- Prometheus & Grafana integrations still work

### 6. Commit Your Changes
```bash
git commit -m "Add my feature"
```
### 7. Push the Branch
```bash
git push origin feature/my-feature
```
### 8. Open a Pull Request

Describe what your change does and why it matters.
## Code Standards

- Follow standard Python formatting (PEP8)
- Avoid committing secrets or credentials
- All YAML files should be properly formatted and validated

## Reporting Issues

If you find a bug, please open an issue including:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Logs/screenshots if applicable

Thank you for helping improve the project!
